# 🏦 Bank Management System

**Author**: [Katharine007](https://github.com/Katharine007)

The **Bank Management System** is a Python-based console application that simulates core banking operations. It allows users to create accounts, perform transactions, and manage account information securely.

## 🚀 Features

- **Account Creation**: Users can open new bank accounts by providing personal details and an initial deposit.
- **Deposit Funds**: Existing account holders can deposit money into their accounts.
- **Withdraw Funds**: Users can withdraw money, ensuring sufficient balance is available.
- **Balance Inquiry**: Account holders can check their current account balance.
- **Account Information Update**: Users can update personal details associated with their accounts.

## 🛠️ Technologies Used

- **Python**: Core programming language for the application.
- **SQL**: Utilizes MySQL to store and interact with database.

## 📂 File Structure

- `deborah.py`: The main script containing the entire application logic.

## 🔑 Getting Started

1. **Prerequisites**:
   - Python 3.x installed on your system.

2. **Installation**:
   - Clone the repository:
     ```bash
     git clone https://github.com/Katharine007/Bank-Management-System.git
     ```
   - Navigate to the project directory:
     ```bash
     cd Bank-Management-System
     ```

3. **Usage**:
   - Run the application:
     ```bash
     python deborah.py
     ```
   - Follow the on-screen prompts to navigate through the various banking operations.

## 📝 Notes

- **Data Storage**: The application uses text files to store account information and transaction histories. Ensure that the script has the necessary permissions to read from and write to files in the directory.
- **Security**: As a console-based application using basic file storage, it is recommended to handle sensitive information cautiously. For production environments, consider implementing robust security measures and using databases for data storage.
